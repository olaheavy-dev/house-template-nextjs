# house-template-nextjs

The Next.js layer of my Copier project templates: a Next.js frontend under `frontend/` for a project generated from [house-template-base](https://github.com/olaheavy-dev/house-template-base), talking to any backend with an OpenAPI schema (FastAPI, ASP.NET Core or an external API).

Built through reviewed pull requests; the design is in the House template plan ("Next.js layer: design").
